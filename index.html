Виджет берёт уровень воды (пост «Горный институт»), температуру воздуха и воды, ветер напрямую из открытого API weather.nord-sup.ru/data (с CORS). Точное значение поста «Елагин Остров» открывается во встроенной странице spbwater.su — на телефоне проверка Cloudflare пройдёт автоматически.
